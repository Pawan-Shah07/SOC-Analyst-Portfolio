# 🔍 SOC Investigation Methodology

My investigations generally follow this workflow:

```text
Security Event
      ↓
Alert Triage
      ↓
Determine Scope
      ↓
Collect Evidence
      ↓
Analyze Logs
      ↓
Enrich IOCs
      ↓
Identify TTPs
      ↓
Map to MITRE ATT&CK
      ↓
Assess Impact
      ↓
Contain / Recommend Response
      ↓
Document Findings
```

The objective is not simply to identify an alert, but to understand:

> **What happened? → How did it happen? → What was affected? → What evidence supports the conclusion? → What should be done next?**
